## О проекте
Виртуальная система сбора и учёта данных на базе Arduino Uno для управления жалюзи по уровню освещённости. Система контролирует:

| Параметр | Датчик | Диапазон |
|---|---|---|
| Освещённость (s1) | LDR | 0–100 % |
| Температура в комнате (s2) | NTC | –20…80 °C |
| Расстояние до шторы (s3) | HC-SR04 | 2–400 см |

**Исполнительное устройство:** сервопривод (жалюзи)
**Индикатор:** белый светодиод (10 мА, R = 180 Ом)
**Период опроса:** T = 2 с
**Порог события:** освещённость > 80 % → сервопривод закрывает жалюзи, светодиод включается
