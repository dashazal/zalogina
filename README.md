# Курсовой проект: Разработка и сопровождение виртуальной системы сбора и учёта данных на Arduino

**Вариант №10: «Жалюзи»**
**Студент:** Залогина Дарья Алексеевна, группа 54-15

## Описание проекта
Виртуальная система на Arduino Uno, которая считывает показания трёх датчиков (LDR, NTC, HC-SR04), управляет сервоприводом (жалюзи) и белым светодиодом по порогу освещённости. Данные выводятся в Serial Monitor, сохраняются в лог-файл, обрабатываются в Node-RED и загружаются в базу данных SQLite.

## Структура репозитория
* `docs/` — схемы (структурная, EasyEDA), скриншоты, пояснительная записка.
* `sim/` — файл `diagram.json` из Wokwi.
* `firmware/` — скетч Arduino (`sketch.ino`).
* `db/` — файлы базы данных (`schema.sql`, `queries.sql`).
* `nodered/` — экспорт потока Node-RED (`flow.json`).
* `data/` — файлы логов (`log.txt`).

## Расчётная часть
1. **Резистор светодиода:** R = (5 В - 3,2 В) / 0,010 А = **180 Ом** (мощность 0,018 Вт).
2. **Шаг АЦП:** ΔU = 5 В / 1024 ≈ **4,88 мВ**. Шаг LDR: 100 / 1023 ≈ **0,098 %**.
3. **Объём данных (T = 2 с):** 86400 / 2 * 3 = 129 600 записей/сутки. Объём = 129 600 * 40 байт ≈ **5,18 МБ/сутки** (около **155,5 МБ** за 30 дней).
